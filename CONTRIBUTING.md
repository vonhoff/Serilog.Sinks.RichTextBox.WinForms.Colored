# Contributing

Contributions to this project are **welcome** and **encouraged**!

## Ways to Contribute

Contributions can include:

* Fixing bugs
* Improving performance
* Adding or enhancing APIs
* Updating documentation
* Promoting the project (blogs, tutorials, etc.)

## Submitting Issues and Pull Requests

Use [GitHub Issues](https://github.com/vonhoff/Serilog.Sinks.RichTextBox.WinForms.Colored/issues/new) to report bugs or suggest features, and include clear steps to reproduce problems so they can be handled quickly.

For significant changes or new features, open an issue first to discuss your proposal before creating a pull request.

## Code of Conduct

All contributors should follow the [Code of Conduct](CODE_OF_CONDUCT.md) to ensure a respectful and welcoming environment.
